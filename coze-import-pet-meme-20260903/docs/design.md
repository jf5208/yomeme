# 宠物 Meme 生成网页 MVP 设计

## 目标

验证用户上传单动物 Meme 模板和自家宠物照片后，能否快速得到“像原 Meme，但动物换成我家宠物”的可下载图片。

## 范围

第一版只做上传、生成、一次调整再生成、预览和下载。不做复杂编辑、社区、多动物、登录、计费或长期素材管理。

## 架构

应用作为独立本机网页运行在 `pet-meme-mvp`。浏览器负责上传和预览，本机 Flask 后端负责保存临时图片、组装提示词并调用 Gemini 图片编辑接口，密钥只保存在本机 `.env` 或环境变量中。

## 生成要求

默认提示词要求模型保留原 Meme 的文字、构图、动作、表情、透明度、模糊、压缩痕迹和低清网图质感，只替换单个动物主体。二次生成时，把用户调整意见追加到同一组约束后面。

## 验收

- 少传模板或宠物图时给出中文提示。
- 上传 1 张模板和 1 到 3 张宠物图后可以生成。
- 生成成功后页面能预览并下载 PNG。
- 没有 `GEMINI_API_KEY` 时给出明确提示。
