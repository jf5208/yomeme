# 宠物 Meme 微信小程序

这是现有网页之外的独立微信小程序版本，不会改动已经上线的网页或 Coze 项目。

第一版包含：新用户 300 积分、每次生成或调整消耗 100 积分、失败自动退回、一次调整、保存与分享、充值码兑换，以及隐藏的管理员发码页。暂不接微信支付。

## 开始使用

1. 按 [CloudBase 上线说明](docs/cloudbase-setup.md)完成后台配置。
2. 用微信开发者工具导入本目录。
3. 完成环境配置后，在开发者工具中上传并提交微信审核。

本地自动检查：

```bash
npm test
```

真实密钥只能填写在云函数环境变量中，不能写进小程序代码、GitHub、聊天记录或截图。
